# Swoole是什么

?> `Swoole` 是一个使用 `C++`和`PHP` 语言编写的并行网络通信引擎，基于异步事件驱动和协程，为 `PHP` 提供[协程](/coroutine)、[高性能](/question/use?id=how-is-the-performance-of-swoole)网络编程支持。它内置了多种通信协议的网络服务器和客户端模块，可快速实现 `TCP/UDP 服务`、`高性能 Web`、`WebSocket 服务`、`物联网`、`实时通讯`、`游戏`、`微服务` 等场景，帮助 `PHP` 突破传统 Web 领域的限制。
